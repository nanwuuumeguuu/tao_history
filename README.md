# インタラクティブ歴史地図・年表 Webアプリ 仕様書 v1

## 0. この文書について

紀元前から現代までの世界各地域の「領域の変遷」を、地図アニメーションと年表で表現するWebアプリの仕様書です。複数人でWikiのように編集できることを目指します。本書は第一版であり、各項目は後から変更できるよう設計方針を明記しています。

---

## 1. 目的とコンセプト

### 1.1 つくるもの
時間スライダーを動かすと、地図上の各勢力の「領域」がぬるっと変化していく世界史ビューア。国名・国境が今と違う時代、境界が曖昧で「膨らみ」のある勢力圏を、正確さより**歴史の実像に近い曖昧さ**で表現する。

### 1.2 設計思想
- **曖昧さを尊重する**：古代の領域に明確な国境線は存在しない。ぼかし・半透明・重なりで「およその勢力圏」を表す。
- **軽さ優先**：ビルド不要、`index.html` を開けば動く。データはJSON。
- **編集できる**：閲覧だけでなく、誰でも領域・年表項目を追加・修正できるWiki的な編集モードを持つ。
- **粒度を選べる**：「帝国レベル」だけ見たい人と「個々の王・事件」まで見たい人、両方に対応。

### 1.3 対象地域（10ブロック）
ヨーロッパ / アメリカ大陸 / 中国（東アジア）/ 韓国（朝鮮半島）/ インド（南アジア）/ イラン（ペルシア）/ 中東 / アフリカ / オーストラリア / 南米
※ヨーロッパは、近代以降に現在の国々へ分岐して以降の歴史も扱う。

## 4. 地図表現（方式A：簡略化ベクター）

### 4.1 基本方針
実際の国境ではなく、手描きに近い簡略ポリゴンで領域を描く。ベース地図は簡略化した世界の海岸線SVG（軽量）。

### 4.2 「膨らみ・曖昧さ」の表現（標準採用）
- **ぼかし縁取り**：領域の縁をSVGフィルタ（feGaussianBlur）でにじませ、境界が確定していないことを表す。
- **半透明の重なり**：勢力圏が重複する地域（係争地・緩衝地帯）は、複数領域が半透明で重なって濃く見える。
- 補助として、点線・かすれ境界を項目ごとに選べるオプションも用意。

### 4.3 アニメーション
時間スライダーを動かすと、ある領域が次の時代の形へ**モーフィング（頂点補間）**で滑らかに変化。出現・消滅はフェードイン／アウト。滑らかさより軽さを優先し、補間は単純な線形で開始。

### 4.4 領域データの持ち方
1つの「領域（Territory）」は、複数の時代スナップショットを持つ。各スナップショットが「その年におけるポリゴン形状」。スナップショット間はアプリ側が補間する。

---

## 5. 粒度（ズームレベル）

設定で3段階を切り替え。各エンティティに「どの粒度から表示するか」のレベルを持たせ、フィルタする。

| レベル | 名称 | 表示されるもの（例） |
|---|---|---|
| 1 | 大区分 | 主要な帝国・文明圏（ローマ、漢、マウリヤ 等） |
| 2 | 王朝・国家 | 個別の王朝・国家、主要な領域変化 |
| 3 | 詳細 | 個々の王・事件・都市・小勢力 |

## 6. 画面構成（UI）

```
┌─────────────────────────────────────────────┐
│ ヘッダー：タイトル / 粒度切替 / 編集モード切替 / 保存・読込 │
├──────────────────────────────┬──────────────┤
│                              │              │
│         地図エリア（SVG）      │  年表パネル    │
│     ・領域ポリゴン             │  ・現在時点の   │
│     ・ぼかし／重なり           │    出来事一覧   │
│     ・クリックで詳細           │  ・クリックで   │
│                              │    地図と連動   │
│                              │              │
├──────────────────────────────┴──────────────┤
│ 時間スライダー：紀元前3000 ───●─── 現代        │
│ 再生／一時停止ボタン、地域フィルタ             │
└─────────────────────────────────────────────┘
```

### 6.1 主要コンポーネント
- **時間スライダー**：BC/ADを1本の軸で。再生ボタンで自動送り。
- **地図**：SVG描画。領域クリックで詳細ポップアップ。
- **年表パネル**：現在時点±の出来事を時系列表示。
- **粒度セレクタ**：1〜3段階。
- **地域フィルタ**：10ブロックのON/OFF。
- **編集ツールバー**：編集モード時のみ表示。

## 7. 編集機能（Wiki的）

### 7.1 モード
- **閲覧モード**（既定）：見るだけ。
- **編集モード**：領域・年表項目を追加/修正/削除。

### 7.2 編集できること
- 領域の新規作成（ポリゴンを地図上でクリックして頂点を打つ）
- 既存領域の形状・色・名前・時代の編集
- 曖昧さ表現の種類選択（ぼかし／点線／重なり）
- 年表項目（出来事）の追加・編集
- メタ情報（作成者・出典メモ・確度）の記入

### 7.3 確度（confidence）フィールド
領域や事件に「確度：高／中／推定」を持たせ、推定のものは見た目でも区別（例：より強いぼかし）。※過度に断定的な表現を避けるための仕組み。

## 9. 技術スタック

| 項目 | 採用 | 理由 |
|---|---|---|
| 描画 | 素のHTML + JavaScript + SVG | ビルド不要、軽い、ポリゴン描画に最適 |
| フレームワーク | なし（バニラJS）で開始 | 軽さ最優先。肥大化したらSvelte等を検討 |
| データ | JSONファイル | ローカルで完結、将来サーバー化しやすい |
| 保存 | File System Access API ／ ダウンロード | ローカルファイル書き出し |
| AI初期データ | 生成したJSONを同梱 | 叩き台として編集前提 |

`index.html` 一枚 ＋ `data.json` ＋ 簡略地図SVG、で動くことを目標にする。

---

## 10. AI初期データの生成方針

- AIが各地域・各時代の主要勢力を選定し、叩き台JSONを生成。
- ポリゴンは「およその範囲」を簡略頂点で。正確さより雰囲気。
- **断定を避ける**：確度フィールドを適切に付け、不明な範囲は estimated とし強めのぼかしに。歴史的に議論のある呼称・範囲は note に留保を記す。
- 粒度レベル1（帝国級）から埋め、段階的に2・3へ拡張。
