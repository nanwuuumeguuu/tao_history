# tao_studio の規則

このリポジトリの目的は、曖昧な着想を学術の場でも通用する水準まで固めること。

## 絶対に守ること

- **未確認が既定。** 新しい主張の `status` は必ず `unverified`。自分の知識だけで `verified` にしない。
- **確認済みには記録が要る。** `verified_by` `verified_on` と、原文つきの `evidence_for` が埋まっていない主張は `verified` にできない。
- **原本は書き換えない。** `raw/` は追記のみ。主張は必ず `origin` で原本の場所を指す。
- **台本は台帳のIDだけを引用する。** `works/` の文章に、`ledger/` にない事実の主張を書かない。
- **書く役と確かめる役を分ける。** 確かめる役（`verifier`）は文章を直さず、指摘だけ返す。
- **分からないことは `cannot-judge`。** 空欄を推測で埋めない。出典を作らない。

## 主張の六種類（claim_type）

| 値 | 意味 | 作品での言い方 |
|---|---|---|
| FACT | 実験・観測で確かめられた事実 | 断定してよい |
| THEORY | 確立した理論の内容 | 「理論では」「計算の上では」 |
| INTERPRETATION | 解釈。立場が分かれるもの | 「〜と読む立場がある」。証拠に使わない |
| METAPHOR | 比喩 | 「〜のように」。物理の主張に見せない |
| FIRST-PERSON | 一人称の体験 | 「私には〜と感じられた」 |
| METAPHYSICAL | 形而上・価値の主張 | 哲学の主張として出典つきで |

## 量子の言葉の点検（lint）

1. 「観測」「測定」は物理的な相互作用。心のことではない。
2. 意識が波束を収縮させる、は少数派の解釈。発見ではない。
3. 量子もつれは信号を運ばない。
4. エネルギー・周波数・波動・場は、単位を付けられないなら METAPHOR。
5. 量子の効果を脳や社会に当てはめるなら、なぜ壊れずに残るかの議論が要る。
6. 解釈の選択は INTERPRETATION。証拠として引かない。
7. 著名な物理学者の言葉は一次資料で確かめる。

## 技法カード

- Notch の `.dfx` はバイナリで直接は読めない。`tools/notch_dump.js` を Notch 内で実行してノードグラフをログに書き出し、`tools/notch_log_to_graph.py` でつなぎ図にする。値や入力接続など書き出せない部分は画面の画像で補い、ノード名とパラメータ名をマニュアルMCPで照合する。
- 配布物・他人のコードは `license` と `source` を必ず書く。条件が不明なら `license: unknown` とし、作品には使わない。
- 再現できたカードだけ `status: verified`。

## 進め方

- 一度に扱う原本は1ファイル。終わったら何件の主張を作り、何件が未確認かを報告する。
- 迷った分類は候補を二つ挙げて理由を書く。
- 有料のAPIを呼ぶ前に見込みの費用を書いて承認を待つ。
