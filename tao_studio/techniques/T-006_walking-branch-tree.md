## 何ができるか
歩く人の連続写真が帯になり、帯が枝分かれして樹になる。引くと樹、寄ると人の列。選ばなかった道を、消さずに薄く残す。

## 手順
1. Blender で分岐する曲線を Python で作る（再帰。分岐ごとに太さを分ける）。
2. 歩行の素材を用意する。自分を横から撮って切り抜くのが確実。
3. TouchDesigner の instancing で、曲線上の位置と時間のずれを各コピーに渡す。
4. 白地に乗算で重ねる。実現した枝だけ濃度 100%、ほかは 10〜20%。

After Effects だけで作るなら、パスに沿わせた人物レイヤーに「エコー」。
