# 技法カード

1. `techniques/_template.md` の形で `T-XXX_短い名前.md` を作る。
2. 「何ができるか」「仕組み」「手順」「自動化」「注意」を埋める。見て分かったことと推測を分けて書く。
3. Notch の場合：
   - まず `raw/workshop/<course>/graphs/` に書き出し済みのつなぎ図があるか見る。無ければ、本人に `tools/notch_dump.js` の実行を頼む。
   - 書き出しに含まれないもの（パラメータの値、キーフレーム、プロパティへの入力接続）は、画面の画像か本人の説明で補い、補った箇所をそう明記する。
   - 値を読みたいノードの種類が決まったら、マニュアルでプロパティ名を調べて `TAO_PROPS` に足す案を出す。
   - ノード名とパラメータ名は Notch のマニュアル検索で照合し、見つからなかった名前に `[?]` を付ける。
4. `source` と `license` を必ず書く。条件が分からなければ `unknown` とし、「作品には使わない」と注意に書く。
5. `status` は `unverified`。本人が実際に再現できたと言ったら `verified` にする。
6. 内容に物理や哲学の主張が含まれるなら、カードには書かず `split` に回す。
