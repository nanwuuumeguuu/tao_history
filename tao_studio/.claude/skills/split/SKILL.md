# 主張に割る

1. 対象は `raw/` の1ファイルだけ。
2. 一文ずつ、単独で真偽を問える主張に分ける。「AだからB」は A、B、「AならB」の三つに分ける。
3. それぞれに `claim_type` を一つ付ける（CLAUDE.md の六種類）。迷ったら候補を二つ挙げ、`note` に理由を書く。
4. 操作化の問いを当てる：
   - 物理学者が受け入れる一文に言い直せるか。
   - それが偽だったら、どんな観測が違ってくるか。
   - 違いが無いなら METAPHOR / METAPHYSICAL / FIRST-PERSON のどれか。METAPHOR なら「何を何にたとえているか」「どこで壊れるか」を `note` に書く。
5. `ledger/_template.yaml` の形で `ledger/C-XXXX.yaml` を作る。番号は既存の最大＋1。
6. **`status` はすべて `unverified`。** 自分の知識で確かめたことにしない。
7. 既存の主張と重なるものは新規に作らず、`origin` を追記する。
8. 報告：作った件数、種類ごとの内訳、分類に迷ったもの。
