# 点検

対象の文章について、次を順に確かめて一覧で返す。文章は直さない。

1. 事実の主張で、`ledger/` の ID が付いていないもの。
2. 引用している主張の `status` が `verified` でないもの。
3. INTERPRETATION / METAPHOR の主張を、断定の形で書いているもの。
4. CLAUDE.md の「量子の言葉の点検」7項目に触れるもの。
5. `glossary.md` の「使わない言い方」に当たるもの。
6. 人名、年代、書名。

それぞれ、該当箇所、理由、直し案を書く。重大／提案／些細に分ける。
