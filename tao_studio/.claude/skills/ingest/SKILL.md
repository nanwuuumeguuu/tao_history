# 取り込み

1. 素材の種類を見分け、置き場所を決める：`raw/chat/` `raw/audio/` `raw/sketch/` `raw/sns/` `raw/workshop/`。
2. ファイル名は `YYYY-MM-DD_短い題.md`。冒頭に日付、出どころ、関わった人を書く。
3. **要約しない。** 発言や文面はそのまま書き写す。
   - 録音：文字起こしを話者と時刻つきで置く。音声ファイル本体は Git に入れず、保存場所を書く。
   - 手書き・画像：読み取った文字を書き、自信のない箇所に `[?]` を付ける。
   - SNS・動画：URL、投稿者、キャプション、見た内容の記述。技法の話なら `technique-card` へ回す。
4. 既存の `raw/` ファイルは書き換えない。訂正は末尾に追記する。
5. 終わったら、置いたファイルと、次に `split` をかけるかを報告する。
