# tao_studio

曖昧な着想を、確かめられる主張と再現できる技法に変えて、作品にするための作業場。

## 三つの棚

| 棚 | 置くもの | 規則 |
|---|---|---|
| `raw/` | 会話、録音の文字起こし、手書き、SNSで見たもの、ワークショップの配布物 | 追記のみ。書き換えない |
| `ledger/` | 主張を1件1ファイルで。種類・状態・出典つき | 最初は必ず `unverified` |
| `techniques/` | 技法を1件1ファイルで。道具・手順・自動化・利用条件 | 自分で再現できたものだけ `verified` |

調査で見つけた道具・コード・参照先は `catalog/` に目録としてまとめてある。

ほかに `glossary.md`（用語集）、`sources/`（文献）、`wiki/`（主題ごとのまとめ）、`works/`（作品ごとの台本・ショット表・出典表・訂正記録）。

## 流れ

1. 素材を `raw/` に置く（`ingest` スキル）
2. 主張に割って種類を付ける（`split` スキル）→ `ledger/`
3. 別の目で確かめる（`verify` スキル、`verifier` エージェント）
4. 言葉の滑りを点検する（`lint` スキル）
5. 台本は `ledger/` のIDだけを引用して書く

技法は `technique-card` スキルで `techniques/` にカード化する。

## 始め方

Claude Code でこのフォルダを開き、「raw/chat/ に今日の会話を取り込んで、主張に割って」と頼む。
